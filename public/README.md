# `public/` (Uproszczony Podręcznik Webowy)

* **Status:** ⚪ `[OPCJONALNY]`

Katalog zawiera bezserwerowe pliki internetowe podręcznika KTANE:

- [`index.html`](index.html) — strona główna i nawigacja po modułach.
- `pl/` — wersja polska podręcznika (`Module*.html` i `index.html`).
- `css/` — arkusze stylów (`main.css`, `normalize.css`).
- `img/` — diagramy, wykresy i symbole modułów bomb.
- `Module*.html` — angielskie wersje 13 modułów podręcznika.
